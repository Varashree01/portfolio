# Varashree H A Portfolio

A premium dark-mode developer portfolio shaped like a VS Code workspace. It presents the portfolio itself as an interactive coding environment with an explorer, tabs, terminal commands, and a command palette.

## Live Demo

https://portfolio-rg1on4l8p-flamex-01.vercel.app/

## Features
- Dark IDE-inspired interface with a polished workspace layout
- Explorer sidebar for file-style navigation
- Editor tabs and content switching for profile sections
- Integrated terminal with commands such as `whoami`, `skills`, `projects`, `research`, and `contact`
- Command palette and quick file search via `Ctrl/Cmd + K` and `Ctrl/Cmd + P`
- Terminal controls for minimize, shrink, and expand behavior similar to VS Code
- Responsive layout for desktop, tablet, and mobile screens
- Reduced-motion support and accessible keyboard shortcuts

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Vercel

## Run locally
1. Open `index.html` in a browser, or
2. Serve the folder locally with a lightweight static server, for example:

   python -m http.server 8000

3. Visit http://localhost:8000

## Deployment
This portfolio is ready to deploy as a static site on GitHub Pages, Netlify, or Vercel. When connected to GitHub, pushing the latest changes to the main branch will trigger a fresh deployment on Vercel.
